# 🌍 Multilingual AI Team

A multilingual multi-agent AI system built using Agno and Groq APIs.

## 🚀 Features

- English AI Agent
- Hindi AI Agent
- Chinese AI Agent
- Team-based AI coordination
- Automatic language detection
- Responses generated using Groq LLMs

---

## 🛠️ Tech Stack

- Python
- Agno Framework
- Groq API
- dotenv

---

## 📂 Project Structure

```bash
AGENTIC-AI-
│
├── Teams.py
├── requirements.txt
├── .gitignore
├── README.md
└── .env
```

---

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Dishaagarwal-2006/AGENTIC-AI-.git
```

Move into the project folder:

```bash
cd AGENTIC-AI-
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## 🔑 Setup Environment Variables

Create a `.env` file:

```env
GROQ_API_KEY=your_api_key_here
```

---

## ▶️ Run the Project

```bash
python Teams.py
```
